## 📖 About the Project

**AURA** is a revolutionary AI-powered application designed for both **online and offline environments**. It goes beyond being a simple assistant — offering emotional support, answering queries, and acting as a multi-role expert, even without an internet connection.

**AURA is more than an app. It’s a companion.**

This intelligent mobile application integrates multiple AI services from industry-leading providers alongside a custom-built offline AI module. It empowers users to access advanced natural language processing and generative AI services for diverse purposes, including text generation, translation, conversational AI, and personalized responses.

**AURA** bridges the gap between advanced AI and areas with limited or unreliable internet access by delivering on-device intelligence for critical areas such as computer vision, natural language processing, and speech recognition.

## 📊 Core Features

### 1️⃣ Image Classification

Classify images into categories locally using **EfficientNet-Lite0**.
*Use cases:* Plant species ID, product recognition, offline photo tagging.

### 2️⃣ Object Detection

Real-time object detection using **YOLOv8n**.
*Use cases:* Security systems, AR shopping, surveillance.

### 3️⃣ Face Detection & Recognition

Detect faces with **BlazeFace** and recognize them via **FaceNet Lite**.
*Use cases:* Secure login, visitor logs, attendance management.

### 4️⃣ Text Classification

Analyze text inputs offline using **DistilBERT Tiny**.
*Use cases:* Sentiment detection, spam filtering, smart inbox sorting.

### 5️⃣ Text Generation

Auto-generate text and smart replies offline using **GPT-2 Tiny**.
*Use cases:* Captions, status suggestions, chatbots.

### 6️⃣ Speech Recognition

Convert speech to text offline with **Vosk Small**.
*Use cases:* Voice notes, offline command systems, accessibility tools.

### 7️⃣ Pose Estimation

Track human keypoints in real-time with **PoseNet**.
*Use cases:* Fitness apps, gesture control, AR games.

## 🏗️ Technical Architecture

* **Frontend:** Flutter (with `tflite_flutter`, `onnxruntime_flutter`)
* **Offline AI Models:** Quantized `.tflite` and `.onnx` models
* **Online AI Services:** Custom APIs (with secure API keys)
* **Model Management:** On-device storage and version control
* **Data Privacy:** No data leaves the device unless user permits via online APIs

---

## 🔒 API & Model Management

* API keys stored securely using native encrypted storage
* Offline models bundled as app assets or via encrypted OTA updates
* Supports easy local model updates and secure key rotation
